## 1. 本项目的生存数据

临床表 `NSCLC-Radiomics-Lung1.clinical-version3-Oct-2019.csv`（422 例）中与生存有关的两列：

| 列名 | 含义 | 取值 |
|---|---|---|
| `Survival.time` | 从治疗开始到事件或随访结束的时间 | 数值，单位**天** |
| `deadstatus.event` | 事件指示（event indicator） | `1` = 死亡；`0` = 右删失 |

其余可用作分组/协变量的列：`age`、`gender`、`Histology`、`Overall.Stage`、
`clinical.T.Stage` / `Clinical.N.Stage` / `Clinical.M.Stage`。

注意：这张表只有**终点事件=死亡**，没有复发时间；TNM 部分编码含义已丢失
（见 `data/README.md` 的「已知缺陷」），建模时要当分类变量处理或剔除。

## 2. 为什么不能直接用 t 检验 / 卡方

这是 D14 的核心问题，四个理由：

1. **T 不服从正态分布**：生存时间非负、右偏、长尾，t 检验的前提不成立。
2. **删失让"均值"不可算**：删失样本只知道 `T > 随访时间`，不知道真实 T；
   直接把删失样本删掉会丢掉信息、高估事件发生率。
3. **关注点不是"平均活多久"，而是"随时间的风险"**：t 检验比较均值，
   生存分析比较整条生存曲线或风险函数。
4. **只看"是否死亡"的卡方检验丢掉了时间**：同样 50% 死亡，
   1 年内死一半和 5 年内死一半完全不同，卡方分不出来。

对"是否死亡"做卡方还有两个具体缺陷：随访时间长短不一的样本被同等对待；
删失样本无法归入"死亡/存活"的任何一格。

## 3. 基本量

| 符号 | 名称 | 定义 |
|---|---|---|
| `T` | 真实生存时间 | 从起点到事件发生的时间，`T ≥ 0` |
| `C` | 删失时间 | 随访结束、失访等导致观察终止的时间 |
| `Y` | 观察时间 | `Y = min(T, C)` |
| `δ` | 事件指示 | `δ = 1` 若 `T ≤ C`（观察到事件），否则 `0` |
| `S(t)` | 生存函数 | `S(t) = P(T > t)`，`S(0) = 1`，单调不增 |
| `h(t)` | 风险函数 | 瞬时事件率 |

风险函数与生存函数的关系：

```text
h(t) = lim_{Δt→0} P(t ≤ T < t+Δt | T ≥ t) / Δt = f(t) / S(t)
S(t) = exp( -∫_0^t h(u) du )
```

**右删失（right censoring）** 是生存分析存在的根本原因：到研究结束时还没死、
或失访，只能确定 `T > 观察时间`。标准假设是**非信息删失**——删失时间与生存时间
在给定协变量下独立。报告里需要说明这一点，否则结论不成立。

**删失 ≠ 缺失数据**：缺失是"没观测到"，删失是"观测到了，只是被截断在某个时间之后"，
它携带信息（至少活了这么久），必须进入风险集。

## 4. Kaplan–Meier 估计

把每个事件时点的条件生存概率连乘：

```text
S_hat(t) = ∏_{t_i ≤ t} (1 - d_i / n_i)
```

- `t_i`：第 i 个**事件**发生的时点（按时间排序、去重）；
- `d_i`：`t_i` 时刻发生事件的例数；
- `n_i`：`t_i` 时刻仍在风险集里的例数（尚未发生事件、也尚未删失）。

三个关键点：

1. 曲线只在**事件时点**下降，是阶梯函数；
2. **删失者不贡献事件**，只是在该时点之后退出风险集，所以会降低后续的 `n_i`；
3. 某个时点既有事件又有删失时，惯例先把删失者移出风险集，再计算该时点的
   `d_i / n_i`（不同软件可能略有差异，但影响很小）。

置信区间用 Greenwood 公式；曲线尾部风险集很小，CI 会迅速变宽，不宜过度解读。

## 5. log-rank 检验

比较两组（或多组）**整条生存曲线**是否相同：

```text
H0: S_1(t) = S_2(t) 对所有 t
```

做法：在每个事件时点构造 2×2 表，算该时点的期望事件数 `E_i` 与方差 `V_i`，
把各时点的观测减期望累加：

```text
χ² = ( Σ (O_i - E_i) )² / Σ V_i ,   df = 组数 - 1
```

特点：

- 只用**事件时点**，不要求分布假设；
- 每个时点都按当时的风险集计算期望，等价于"随时间加权"；
- 对"曲线交叉"不敏感（交叉时 log-rank 可能不显著），此时可考虑
  Peto–Peto 或加权 log-rank。

与卡方的本质区别：卡方只看终点状态的比例，log-rank 利用事件发生的**顺序和时点**，
并正确处理删失。所以"两组的死亡比例一样"不代表"生存过程一样"。

## 6. 中位生存时间

```text
median = min{ t : S_hat(t) ≤ 0.5 }
```

如果整条曲线始终高于 0.5（随访期内死亡不足一半），中位数**不可估计**，
报告必须写「未达到（not reached）」，不能写成 0、NA 或取最后一个时点。

同时应报告：每组样本量、事件数、随访时间范围——只有 p 值没有这些信息，
读者无法判断结论的可靠性。

## 7. 常见错误

| 错误 | 为什么错 |
|---|---|
| 删掉删失样本再分析 | 丢弃"活过 t"的信息，高估风险、低估生存 |
| 把删失当作事件 | 把"不知道"当成"死亡"，低估生存 |
| 用 t 检验比较生存时间 | 正态假设不成立，且删失样本无法进入均值 |
| 对"是否死亡"做卡方 | 丢掉时间信息，也无法处理删失 |
| 中位不可估计时写 0 或 NA | 应写「未达到」并说明随访时长 |
| 只报 p 值 | 缺样本量、事件数、效应量，结论不可复核 |
| 在训练集上报告 C-index | 高估性能，必须在未参与训练的样本上报告 |
| 不做 PH 检验就用 Cox | 比例风险假设不成立时 HR 无意义 |
