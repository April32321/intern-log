# Markdown 速查

## 够用的 5 样语法

- 标题：`# 一级`、`## 二级`、`### 三级`，不要从 `#` 直接跳到 `###`
- 列表：`- 条目`，子项缩进两个空格
- 代码块：三个反引号加语言名，例如 ` ```bash `
- 行内代码：用反引号包住命令，例如 `git status`
- 链接：`[文字](https://example.com)`

## VS Code 源码 ↔ 预览

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 侧边预览（边写边看） | `Cmd+K`，松开再按 `V` | `Ctrl+K`，松开再按 `V` |
| 全屏预览（只读） | `Cmd+Shift+V` | `Ctrl+Shift+V` |
| 回到源码 | 关闭预览标签页 | 关闭预览标签页 |

预览是只读的，打不了字是正常的；内容要在源码里改，预览会实时刷新。

## 我踩过的渲染坑

1. `#` 和标题文字之间必须有空格，写成 `#标题` 不会渲染。
2. 链接地址里混入中文引号、全角括号或空格，点击会 404。
3. 关于 Cmd+K V：在 macOS 上的正确按法是——按住 Cmd 不放，按 K；两个键都松开；再单独按 V（不要再按 Cmd）。
