# 文件与传输命令

**加粗**为不可改动部分（命令名、选项、固定写法）。

1. **`realpath`** `tdr.zip` — 打印文件的绝对路径。
2. **`mkdir`** `test` — 新建目录 `test`。
3. **`rm -r`** `test` — 递归删除目录及其内容，不可恢复。
4. **`cd ~/`** — 回到用户主目录。
5. **`ls`** `test01` — 列出目录内容，不含隐藏文件。
6. **`rsync -avP`** `test01/.profile pvmed190:/home/jiaqiwang/test03/` — 把 `.profile` 传到远端 `test03/`；`-a` 保留属性，`-v` 显示过程，`-P` 显示进度并支持续传。
7. **`ls -a`** `test01` — 列出全部内容，含隐藏文件。

注：第 6 条原记录写作 `sync -avP`，应为 `rsync -avP`；`pvmed190` 是 SSH 别名（端口 3225），目标目录需事先存在。
