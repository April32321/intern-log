> 配图（路径相对 `report.md` 所在目录）：图 1 管线（见 `report.md` §3.2）、图 2 `results/figures/km_by_stage.png`、图 3 `nsclc-cox/results/figures/cv/cindex_boxplot.png`、图 4 `nsclc-cox/results/figures/report/binwidth_sensitivity.png`
>
> 全文只使用已审计数字；所有口径限定：**内部 5×10 交叉验证**、**399 例分析集**、**SD 不是 95% CI**、**bootstrap CI 不是折间波动**。

## 一、做了什么

20 个工作日内，从零打通一条"公开 CT → 定量特征 → 生存预测"的可复现管线：

1. **可重建环境**：Docker 镜像 + Conda 三层版本锁（`environment.yml` / `conda-explicit.txt` / `pip-freeze.txt`），linux-64 与 osx-arm64 双平台重建成功，`env/rebuild.sh` 一条命令复原。
2. **数据到位**：TCIA NSCLC-Radiomics v4，422 例、1,265 个序列、52,073 个 DICOM、35.78 GB，双端计数与哈希一致；CT 切片 51,230 层，层厚全为 3.0 mm。
3. **特征提取**：自实现 RTSTRUCT 栅格化（even-odd + XOR），PyRadiomics 3.0.1 按论文口径（25 HU 分箱、不重采样、Coif1 小波），全量 422/422 完成，**每例 537 维、0 缺例 / 0 零方差 / 0 非有限值**。
4. **评估协议先定后跑**：399 例固定分析集（422 减 22 例缺 age、1 例缺 Stage），5 折 × 10 次重复、seed 42，共 50 个测试折；方差过滤、去冗余、单变量筛选、标准化、LASSO 选 alpha 全部封在训练折内。

## 二、结果（399 例 / 352 事件 / 50 折）

| 模型 | C-index 均值 ± SD | bootstrap 95% CI |
|---|---:|---|
| 仅临床（7 项） | 0.530 ± 0.026 | 0.527 [0.495, 0.558]（**含 0.5**） |
| 论文 4 特征签名 | 0.581 ± 0.038 | 0.576 [0.543, 0.608] |
| 折内 LASSO-Cox | 0.583 ± 0.035 | 0.579 [0.551, 0.608] |
| 临床 + 影像 | 0.581 ± 0.034 | 0.577 [0.548, 0.605] |

五个要点，全部为描述性表述：

- **signature 优于随机**：bootstrap 95% CI 下限 0.543 > 0.5，验收判据第 4 条满足。
- **临床基线不能声称优于随机**：CI 含 0.5。已核对为本队列分期判别力弱（stage_bin 单变量 HR 0.93 [0.74–1.16]、log-rank p=0.53），不是编码错误。
- **三条影像路线打平**：0.581–0.583 之间差别远小于折间波动，说明"影像里确实有信号"，但**不能**说明"某一组特征更好"。
- **LASSO 极不稳定**：每折平均选 11.3 个特征，范围 2–42；50 折中至少入选一次的特征有 99 个。
- **过拟合情况**：签名模型训练−测试 gap 仅 0.003，LASSO 为 0.049，联合模型 0.057——"让数据自己挑"更容易学到训练折噪声。

**方向核对**：论文 4 个特征的风险方向 4/4 一致（Energy↑→差、Compactness2↑→好、两处 GLN↑→差）；Compactness2 为边界证据（HR 0.90，CI 上界 1.00）。这是定性核对，不是效应量复现。

**量纲核对**：Energy 统一到 `HU+1024` 后中位数为论文的 1.03×（同数量级）；HU 口径下为 0.03×，已作为敏感性处理。

**分箱敏感性**：binWidth = 10 / 25 / 50 HU 下，固定签名 C-index 为 0.580 / 0.581 / 0.581（全距 0.0009），LASSO 为 0.583 / 0.583 / 0.590（全距 0.007，非单调）。**判别力稳健，但 LASSO 特征选择随分箱重排且非单调**（如 `wavelet-LHL_glcm_MCC` 入选率 0.08 / 0.60 / 0.76）——性能稳健 ≠ 某个 signature 稳健。

**校准**：1 年 / 2 年 ICI = 0.076 / 0.050，预测生存率值域仅 0.49–0.71（1 年），与 C-index≈0.58 一致，不据此声称临床可用。

**图 2（KM 按 stage）怎么读**：421 例按早期与晚期分组的生存曲线，在约 1000–1500 天处出现交叉，log-rank p=0.532。这是整个项目里"提醒不要只看单一指标"的关键——如果只报一个 log-rank p 值，会得出"分期与生存无关"的错误结论；把曲线画出来才能看到两组风险在时间上换了方向。

**图 3（箱线图）怎么读**：每个箱子代表一种模型 50 个测试折的 C-index 分布。看三件事——中位数位置、箱体高度（折间波动）、箱体之间的重叠程度。四个模型的箱体大幅重叠，这正是"打平"的直观证据；三个影像模型的箱体整体高于临床模型约 0.05，则对应"相差约 0.05"这一表述。**箱体高度是 SD，不是 95% CI。**

**图 4（binWidth 敏感性）怎么读**：左图固定签名三点几乎重合（全距 0.0009），右图 LASSO 第三点略高但偏离不到 0.2 个 SD 且非单调，因此不能据此挑 bw50 作主结果。点与折线为 50 折均值，误差线为折间 SD。

## 三、口径与边界（必须说明）

- 本项目是**方法级复现**。论文训练集 C-index 未报告、4 个特征权重未公开、特征由 Matlab 自研实现，因此不存在可对照的"目标数值"。论文的 0.65 / 0.69 / 0.69 来自 Lung2 与两个头颈队列，本项目**没有**外部队列，两者不可比较。
- **内部交叉验证 ≠ 外部验证**；**SD 不是 95% CI**；**399 例分析集 ≠ 422 例队列**；**bootstrap CI 只反映病人抽样，不含折划分与模型拟合变异**。
- 特征数 537 与论文 440 不可比：PyRadiomics 特征类比论文多，且论文 440 按编号只能复原 431。

## 四、最难的三件事

1. **8 GB 容器的 OOM 误判链**：先猜 fork 不兼容、`/dev/shm` 太小、内存泄漏，一个个用对照实验否定；最终用分块实验（第 1 块 10 例全灭、第 2 块 10 例全成）+ 单例探针，定位到"个别大病例单例峰值超限"，随后把全量迁到 40 核服务器，942.6 s 完成 422 例，并用 5 例独立复算确认数值零差异。
2. **PyRadiomics 3.0.1 装不上**：conda 条款校验、pip 构建隔离、numpy 2.x 移除 `np.float` 三重卡点叠加，最终拆成"conda 建环境 + 单独 `--no-build-isolation` 编译"两段式。
3. **stage 的 HR ≈ 1 且违反 PH**：没有改编码凑指标，而是先用独立脚本核对编码（399 例分布与映射全对），再查出 KM 曲线在 1000–1500 天交叉，用分层敏感性说明"单一半参数 HR 被平均掉了"。

这三件事的共同点是：第一个想到的原因几乎都不是真正的原因。所以后面形成了两个固定动作——先把失败分成可枚举的层级（网络按 DNS / TCP / TLS / 应用层，依赖按 conda / pip / 构建隔离），再设计一个能一次否定最多假说的实验。OOM 那次的分块实验就是典型：如果继续跑全量，可能再花几个小时，也只多一个"又失败了"的结论。

## 五、数据可信度是怎么守住的

四个环节各设一道闸：

- **数据层**：双端文件数与 SHA-256 一致，DICOM 元数据汇总与论文 Table 4 的性别、分期分布逐项核对，IIIb 相差 0.2 个百分点，正好由 1 例 stage 缺失解释。
- **几何层**：4 例孤立缺层病例单独标记，缺层数用 spacing 反推校验；自实现的栅格化与独立的 Slicer 体积对照，几何干净病例相差在 ±1.3% 以内。
- **特征层**：537 列全量复算，0 缺例、0 零方差、0 非有限值；5 例在独立缓存目录重算，最大相对差为 0。
- **建模层**：分析集与折划分在建模前封板，评估脚本只读不写；所有筛选与调参只发生在训练折内部。这一层保证的是"结果不好时没有可调空间"，而不是"结果好看"。

## 六、不足与下一步

| 缺口 | 说明 | 下一步 |
|---|---|---|
| 外部队列 | 无 Lung2 / H&N 数据 | 申请数据后做真正外部验证；这是唯一能与论文 0.65/0.69/0.69 同口径比较的前提 |
| 选择稳定性 | LASSO 特征集随分箱非单调重排 | 以 bootstrap 入选频率做稳定性筛选，或改用弹性网 |
| 样本量 | 399 例 / 352 事件，对高维 LASSO 偏小 | 扩队列或多中心合并 |
| 422 signature-only / 5×5 / apparent C | 未运行，属可选稳健性检查 | 不影响主结论，可按需补 |
| LASSO 路线校准 | 只对固定签名做了校准 | 如需全面比较可补做 |
| 影像模型 PH | 仅检验了临床变量 | 补 Schoenfeld 检验 |
| 几何异常病例 | 4 例保留在分析集中，体积差最大 −26.9% | 做排除后的敏感性分析 |

## 七、一句话总结

这条管线证明了"公开 CT 里能稳定算出一个与生存相关的分数"（signature 95% CI 0.543–0.608），也证明了"具体是哪 4 个特征最好"在本项目的数据规模下不可判定（LASSO 选择非单调、三条路线打平）；所有数字都在内部交叉验证口径下，没有任何一个被当作外部验证结果使用。
